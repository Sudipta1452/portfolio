Work Experience

I'm currently working as a Technical Associate at NAB, where I'm supporting the rollout of a new platform and continuing to grow as a Java and Spring Boot developer.

Before NAB, I worked as a Graduate SAP Technical Consultant at Discovery Consulting, focusing on SAP BTP Extension Development and building solutions with the SAP Cloud Application Programming Model. About Me
